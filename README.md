# Эмулятор UNIX · Вариант 9

Первая практическая по конфигурационному управлению для Даниила Зимина.
Запуск из терминала VS Code: `./run.sh`. Требуется Python 3.9+ с Tk.
Введите `ls "мои файлы"`, `cd`, `unknown`, `exit 2` и `exit`.

## Запуск и настройки

Сборка не требуется. Откройте папку проекта в VS Code. В терминале выполните:

```sh
./run.sh --vfs examples/deep.json --script examples/read.txt
```

Параметр `--vfs` выбирает JSON-образ. Без него создаётся пустой корень.
JSON-объект описывает каталог, строка в Base64 — байты файла. Каталоги могут быть вложенными.
Параметр `--script` задаёт текстовый файл UTF-8 с одной командой на строку.
Окно показывает параметры, команды и ответы. Ошибочная строка сопровождается
номером, после чего сценарий продолжается. После последней строки можно вводить команды вручную.
Для завершения сеанса введите `exit`. Заголовок окна содержит имя пользователя и компьютера.

## Команды

| Синтаксис | Действие |
| --- | --- |
| `ls [путь]` | Список каталога по алфавиту или имя файла |
| `cd [путь]` | Перейти в каталог. Без пути возвращает в корень |
| `cat файл ...` | Показать содержимое текстовых файлов в заданном порядке |
| `tac файл ...` | Показать строки каждого файла снизу вверх |
| `rev файл ...` | Развернуть символы каждой строки |
| `cp источник назначение` | Скопировать файл, в том числе в существующий каталог |
| `cp -r каталог назначение` | Скопировать всё поддерево |
| `rmdir каталог` | Удалить пустой каталог |
| `exit` | Закрыть окно |

Поддерживаются абсолютные и относительные пути, точки и кавычки вокруг имён с пробелами.
Файлы для просмотра должны быть в UTF-8. Копировать можно также двоичные файлы.
После перезапуска образ загружается заново.

## Демонстрация и тесты

```sh
python3 -m unittest discover -s tests -v
./examples/check.sh
./examples/check-errors.sh
./run.sh --vfs examples/deep.json --script examples/change.txt
```

Два shell-скрипта запускают окно по очереди на трёх образах.
В последнем примере можно увидеть успешное удаление пустого каталога,
копирование файла с пробелом в имени и обработку попытки удалить непустой каталог.
Для просмотра пяти этапов разработки выполните `git log --oneline --reverse`.
